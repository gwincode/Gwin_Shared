# Agent instructions for this repo

This repo stores shared configuration for AI coding tools; it is not an application.

- Put each new item in the matching top-level folder (see README.md).
- Never commit secrets, tokens, or machine-specific absolute paths.
- Keep files tool-agnostic unless they live in a tool-specific subfolder; state supported tools at the top of each file.
- Provide `.ps1` and `.sh` variants for scripts when practical (the main machine is Windows).
