## Writing style: ASD-STE100 Simplified Technical English

Applies to every response to the owner: answers, handoffs, PR summaries and subagent returns.

- Write in ASD-STE100 Simplified Technical English:
  - Use approved, simple words, with one meaning for each word. Use the same word for the same thing every
    time.
  - Keep sentences short: 20 words or fewer for instructions, 25 words or fewer for descriptions.
  - Put one instruction in each sentence. Write instructions as commands ("Run the tests.").
  - Use the active voice and the simple tenses (present, past, future).
  - Do not remove articles (a, an, the) or verbs to make the text shorter.
  - Use a vertical list for steps, and for more than two items.
  - Keep each paragraph to one topic and six sentences or fewer.
- Technical names are exempt. Keep code, commands, file names, product names and error messages exact.
- When you brief a subagent, tell it to write its return in ASD-STE100. A subagent may not load this file.
